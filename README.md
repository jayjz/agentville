# AgentVille 1996

Local simulation environment for exploring multi-agent coordination and emergent behavior under controlled conditions.

Built as a high-signal **portfolio and research piece** with a Windows 95 aesthetic. Useful for visualizing agent state, testing coordination patterns, and demonstrating orchestration concepts. It is **not** a production multi-agent platform.

**Live demo:** https://agentville-eosin.vercel.app

---

## Stack

- Next.js 16 + TypeScript
- Tailwind CSS
- Framer Motion
- Pixi.js for sprite rendering
- Canvas Confetti

## Features

- Windows 95 desktop shell with draggable windows
- NPC system with state management
- Retro CRT scanline effects
- Pixel-perfect styling

## Status

Simulation / portfolio demo. See `ROADMAP.md` for planned phases. For production-oriented agent work see [aetherforge](https://github.com/jayjz/aetherforge) and [hvac-ops-agent](https://github.com/jayjz/hvac-ops-agent).
